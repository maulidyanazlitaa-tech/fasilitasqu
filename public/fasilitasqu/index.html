LAPISAN TAMPILAN, SIAP DIPINDAHKAN

Dari HTML ke Laravel.

Paket ini berisi HTML per halaman, layout Blade, partial bersama, CSS, JavaScript murni, dan aset lokal. PHP tidak diperlukan untuk mencoba prototype.

  1. 01
    Unduh paket Laravel

    Ekstrak berkas ZIP. Folder html-prototype/ dapat dicoba sebagai prototype HTML biasa.

  2. 02
    Salin lapisan tampilan

    Pindahkan laravel/resources/views/ ke folder resources/views/ proyek Laravel Anda.

  3. 03
    Salin aset bersama

    Pindahkan laravel/public/fasilitasqu/ ke folder public/fasilitasqu/ proyek Anda.

  4. 04
    Hubungkan rute tampilan

    Ikuti contoh rute di README-LARAVEL.md. Hubungkan controller, autentikasi, dan database sesuai kebutuhan proyek Anda.

Paket berisi starter Laravel 12, struktur MVC/domain, Blade, migrasi, seeder, dan aset. Login serta perubahan data di layar masih simulasi prototype, belum backend produksi.
